# استخراج الأبيات من كتاب «منتقيات شعرية» (PDF)

1. `python3 dump.py الكتاب.pdf` — يقرأ نص كل صفحة مع مواضعه.
2. `pdftotext -layout الكتاب.pdf layout.txt` — نسخة ثانية تُستعمل لإكمال الحروف الناقصة.
3. `python3 parse.py` ثم `python3 build_poems.py` — يُخرج `poems.json` (الأبواب والشعراء والأبيات).

المقاطع التي شُكّ في استخراجها عليها علامة في `flags`، وتظهر للمطوّر في «قائمة المراجعة».
