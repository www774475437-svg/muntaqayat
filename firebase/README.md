# حالة فايربيس (٢٢ نوفمبر ٢٠٢٦): القواعد المنشورة هي firestore.rules (نُشرت اليوم، ومعها صلاحيات المشرفين)

أُنشئ المشروع `muntaqayat`، وقاعدة Firestore (الولايات المتحدة، وضع الإنتاج)، ونُشرت القواعد، وفُعّل الدخول بجوجل، وأضيف نطاق الموقع، وسُجّل تطبيق الويب (`web-config.json`). المطوّر يُعرف ببريده في القواعد. ثم سُجّل تطبيق أندرويد `com.muntaqayat.muntaqayat` ببصمة مفتاح التوقيع، ورُبط كود التطبيق (`lib/services/cloud.dart`): الدخول بجوجل، الرقم الشخصي، الصدارة، الاقتباسات، اختبارات المعلّم بالأرقام، الرسائل، البلاغات، طلبات التصميم، المشتركون، الإحصائيات، وتوثيق المطوّر وإخفاؤه للجميع.

# ربط «منتقيات الشعر» بفايربيس

## ١. أنشئ المشروع
1. افتح https://console.firebase.google.com واضغط «إضافة مشروع» (Add project).
2. اكتب الاسم: `muntaqayat`، وأطفئ Google Analytics، ثم «إنشاء».

## ٢. فعّل تسجيل الدخول
Build ← Authentication ← Get started ← فعّل **Google** و **Email/Password**.

## ٣. أنشئ قاعدة البيانات
Build ← Firestore Database ← Create database ← اختر أقرب منطقة ← Production mode.
ثم افتح تبويب **Rules** وضع محتوى ملف `firestore.rules` الذي بجانب هذا الملف، واضغط Publish.

## ٤. أضف التطبيقين
- أيقونة أندرويد: اسم الحزمة `com.muntaqayat.muntaqayat`.
- أيقونة الويب `</>`: الاسم `muntaqayat-web`.
ثم أرسل صورة الشاشة لصفحة «إعدادات المشروع» (Project settings) ليُكمل ربط الكود.

## تصميم البيانات (قراءات قليلة)
| المجموعة | المحتوى | القراءة |
|---|---|---|
| `users/{uid}` | الاسم، الرقم الشخصي، العدادات (الإعجابات، الاقتباسات، المحفوظ، الأيام)، الاشتراك وتاريخه | **سجلّ واحد = قراءة واحدة** لكل شخص |
| `ids/{رقم ٧ أرقام}` | صاحب الرقم | للبحث بالرقم وخانة المعلّم |
| `quotes` | الاقتباسات (١٠ في اليوم) | تظهر فوراً |
| `tests` | اختبارات المعلّم (حتى ٣٠ طالباً) والنتائج | الطالب يرى «لديك اختبار» فوراً |
| `messages` / `reports` / `orders` | الرسائل، البلاغات، طلبات تصميم الكتب | للمطوّر |
| `stats/summary` | ملخّص الإحصائيات | **قراءة واحدة للمطوّر** مهما كثر المستخدمون |
| `config/app` | إظهار الاشتراك أو إخفاؤه | — |

- العدادات تُرسل من الجوال **دفعة واحدة كل ٦ ساعات**، لا مع كل ضغطة.
- الإحصائيات: كل جوال يزيد عدّاد «دخل اليوم» مرة واحدة في اليوم، فيقرأ المطوّر سجلّاً واحداً.
